Actions

Both actions are free — gas only. Each transaction is confirmed by you in your wallet.

How it works

  1. Connect your wallet Use Binance Wallet or MetaMask on BNB Smart Chain. We only read your address — nothing is signed at this step.
  2. Mint your free badge If your wallet holds an Agent ID, you can mint one soulbound Agent Badge for free (gas only). One badge per Agent ID holder.
  3. Check in every day Come back once per UTC day and check in to grow your streak and climb tiers: New Agent → Bronze → Silver → Gold.

Rules

  • One badge per Agent ID holder. You must hold an Agent ID to mint.
  • One check-in per UTC day. Checking in twice on the same day does nothing extra.
  • Your streak resets if you miss a UTC day.
  • The badge is soulbound — it cannot be transferred to another wallet.
  • Minting and check-ins cost gas only. There is no fee, no token sale, and no payment to anyone.

Please note

Agent Badge is a free collectible badge for Agent ID holders. It has no financial value, is not an investment, and no returns of any kind are promised. Minting and check-ins only cost network gas. Never share your seed phrase or private key with anyone — this site will never ask for them.
